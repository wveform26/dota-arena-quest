# Dota Arena Quest — Telegram Mini App

Фанатская браузерная RPG, которую можно открыть внутри Telegram. Фронтенд статический: сервер или постоянно включённый компьютер для самой игры не нужны.

## Что внутри
- 4 оригинальных героя с разными характеристиками.
- 4 противника, открывающихся по мере повышения уровня.
- Пошаговый бой, навыки, мана, зелья и ответные удары.
- Золото, опыт, уровни, магазин предметов.
- CSS-анимации арены и ударов.
- Сохранение прогресса в `localStorage` браузера.
- Поддержка Telegram Mini Apps API (`Telegram.WebApp`).

## Важно о сохранении
Эта версия сохраняет прогресс на конкретном устройстве/браузере. Прогресс не синхронизируется между устройствами и не хранится на сервере. Для общей таблицы лидеров, серверного инвентаря или защиты от подделки нужен backend.

## Бесплатный хостинг через GitHub Pages
1. Создай аккаунт GitHub, если его ещё нет.
2. Создай новый публичный репозиторий, например `dota-arena-quest`.
3. Распакуй архив и загрузи **содержимое** папки в корень репозитория: `index.html`, `style.css`, `game.js`, `README.md`.
4. В репозитории открой **Settings → Pages**.
5. В разделе **Build and deployment** выбери **Deploy from a branch**.
6. Выбери ветку `main` и папку `/(root)`, нажми **Save**.
7. Подожди завершения публикации. GitHub покажет URL вида `https://ТВОЙ-ЛОГИН.github.io/dota-arena-quest/`.
8. Открой URL в браузере и проверь, что игра загружается по HTTPS.

GitHub Pages — статический хостинг. После публикации сайт остаётся доступен, даже если Debian-компьютер выключен.

## Подключение к Telegram
1. Убедись, что опубликованный URL начинается с `https://` и открывается без входа в GitHub.
2. Открой `@BotFather` в Telegram.
3. Отправь `/mybots` и выбери `DotaArenaQuestBot`.
4. Открой **Bot Settings → Menu Button** (или отправь `/setmenubutton`, если пункт доступен).
5. Установи текст кнопки, например `Играть`, и вставь полный URL GitHub Pages.
6. Для главной Mini App с кнопкой запуска в профиле бота можно настроить **Main App** через соответствующий пункт BotFather, если он доступен.
7. Открой `@DotaArenaQuestBot` и нажми кнопку меню `Играть`.

## Локальный тест на Debian 13
Из папки проекта запусти:
```bash
python3 -m http.server 8000
```
Затем открой `http://localhost:8000` в браузере. Это только локальный тест; production Mini App в Telegram требует публичный HTTPS URL. Остановить сервер: `Ctrl+C`.

## Безопасность
- Не добавляй токен Telegram-бота в эти файлы, GitHub или frontend. Веб-страница публична.
- Если токен случайно попал в чат/репозиторий, отзови его в `@BotFather` и используй новый.
- Не вводи секреты в браузерную консоль и не публикуй файлы `.env`.
- Используется только локальное сохранение, без авторизации и серверной проверки Telegram-пользователя.

## Технологии
HTML, CSS, JavaScript, Telegram Web Apps JS API. Все игровые иллюстрации в этой демо-версии выполнены с помощью emoji и CSS; внешние картинки не требуются.
